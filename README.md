# AIoT Labs

AIoT lab coursework, organized by lab. Filenames retain the original submission identifiers.

| Lab | Contents |
| --- | --- |
| [Lab 1](lab1/) | Checkpoints 1–2 and device entry point |
| [Lab 2](lab2/) | Checkpoints 1–3 and supporting test script |
| [Lab 3](lab3/) | Checkpoints 1–4 and OLED driver |
| [Lab 4](lab4/) | Checkpoints 1–4 |
| [Lab 5](lab5/) | Desktop applications, server implementations, tests, and checkpoint notes |
| [Lab 6](lab6/) | Human activity recognition, ESP32 and desktop code, cloud experiments, tests, results, and report |

See [Lab 6's README](lab6/README.md) for its setup and task instructions, and the checkpoint notes in Lab 5 for those applications.

ESP32 scripts require the appropriate MicroPython firmware and hardware. Desktop and cloud programs have their own dependencies; Lab 6 provides requirements files. API credentials must be configured locally and are excluded from this repository.

Downloaded datasets, model weights, local environments, caches, generated submission archives, and duplicate extracted submissions are excluded. References to generated ZIPs in lab documentation refer to locally generated submission files.
